# Filmsammlung

Barcode scannen und sofort sehen, ob der Film schon in der Sammlung oder auf der Wunschliste ist.
Web-App im Liquid-Glass-Stil, die Daten liegen in einer Google Tabelle (Apps Script als Schnittstelle).

- `index.html`, `styles.css`, `app.js` – die App (ohne Build-Schritt)
- `apps-script/Code.gs` – das Skript für die Google Tabelle (Version 3 mit Covern)
